# FormatPure 🔧
### Free Online Text Formatter + HD Video Effect Generator

Tired of apps with watermarks and logins? 

FormatPure is a 100% free, browser-based tool hub. No signup required.

**Live Demo: https://formatpure.github.io**

### Features
**Text Tools**
- Clean and format messy text
- Remove extra spaces & line breaks
- Convert to Title Case / UPPERCASE / lowercase

**Video Tools** 
- Heartbeat Effect for WhatsApp Status
- Star Overlay Effect
- Download in HD in 10 seconds

### Why FormatPure?
1.  **Free Forever** - No ads, no paywall
2.  **No Login** - Works directly in browser
3.  **Mobile Friendly** - Works on phone
